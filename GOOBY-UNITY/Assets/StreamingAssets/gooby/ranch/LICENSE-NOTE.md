# Ranch models

- `pferd.glb`, `fohlen.glb`, `hindernis_*.glb`, `heuballen.glb`, `trog.glb`, `sattel.glb`, `buerste.glb`: built by the project's own Blender pipeline (GOOBY-GODOT `tools/blender/ranch`), copied from `GOOBY-GODOT/assets/ranch`.
- `scheune.glb`, `scheune_offen.glb`, `scheune_klein.glb`, `scheune_gross.glb`, `silo.glb`, `silo_haus.glb`, `windmuehle.glb`, `windmuehle_turm.glb`, `wasserturm.glb`, `zaun_holz_a.glb`, `brunnen.glb`, `huehnerstall.glb`: Quaternius farm buildings, CC0 (see `License-quaternius-farm-buildings.txt`).
- `schaf.glb`, `kuh.glb`: from `GOOBY-GODOT/assets/ranch/tiere`, Quaternius farm animals, CC0 (see `License-quaternius-farm-animals.txt`).
- `ente_gooby.glb`, `reh_gooby.glb`, `fuchs_gooby.glb`: the ranch's wild animals, built by the project's own Blender pipeline (GOOBY-GODOT `tools/blender/ranch/build_tier.py`, rig with `idle-loop` and `schritt-loop`), copied from `GOOBY-GODOT/assets/ranch/tiere`.
- `tree_oak.glb`, `tree_fat.glb`, `fence_gate.glb`, `fence_simple.glb`, `grass_large.glb`, `plant_bush*.glb`, `flower_*.glb`, `rock_largeA.glb`, `log.glb`, `stump_round.glb`: Kenney Nature Kit, CC0 (see `License-kenney-nature-kit.txt`).
